# 会員ごとの貸出上限 仕様書

## 1. 目的・背景
一部の会員が多くの本を借りたままにすると、他の会員が借りられなくなる。会員ごとに同時に借りられる冊数に上限を設け、蔵書を公平に利用できるようにする。

### スコープ
- 対象: 蔵書画面からの貸出時の上限チェック、上限到達時のメッセージ表示
- 対象外: 会員ごとに異なる上限、上限の変更画面、予約、貸出期間の延長

## 2. 用語
| 用語 | 意味 |
| --- | --- |
| 貸出中の冊数 | その会員の貸出のうち、まだ返却されていないものの件数。同じ本を複数冊借りている場合もそれぞれ 1 冊と数える |
| 貸出上限 | 会員 1 人あたり、同時に貸出中にできる冊数。**3 冊** |

## 3. 対象画面
- 蔵書画面（ヘッダーの「蔵書」）: 会員選択プルダウンと「貸出」ボタン、エラーメッセージ表示欄
- 貸出画面（ヘッダーの「貸出」）: 「貸出中の本」表、「返却」ボタン

## 4. 機能要件
| ID | 条件・操作 | 期待される結果 |
| --- | --- | --- |
| LIM-01 | 貸出中の冊数が 0〜2 冊の会員で「貸出」を押す | 貸出できる（従来どおり）。在庫の貸出可能数が 1 減る |
| LIM-02 | 貸出中の冊数が 3 冊の会員で「貸出」を押す（4 冊目） | 貸出は記録されず、蔵書画面に「貸出上限（3冊）に達しているため貸し出せません」と表示される。在庫の貸出可能数は変わらない |
| LIM-03 | LIM-02 の会員が貸出画面で 1 冊返却した後、蔵書画面で「貸出」を押す | 貸出できる（貸出中の冊数が 2 冊に戻ったため） |
| LIM-04 | 会員 A が 3 冊借りている状態で、別の会員 B が「貸出」を押す | 会員 B は貸出できる（上限は会員ごとに数える） |

### チェックの順序
在庫が 0 の本は従来どおり「貸出」ボタンが押せない。在庫があり、かつ会員の貸出中の冊数が上限に達している場合に LIM-02 のメッセージを表示する。

## 5. 既存機能への影響
- 貸出 API（POST /api/loans）が、上限到達時に HTTP 409 とメッセージを返すようになる。
- 返却・蔵書登録・会員登録・延滞判定は変更しない。
- 既存データで 4 冊以上借りている会員がいても、その貸出はそのまま残る（新しい貸出だけが止まる）。

## 6. 非機能要件
- 特になし（デモ用途。データはサーバー再起動で初期化される）。

## 7. 受け入れテストの前提
- テストで使う本・会員は、テストの中で画面から新しく登録する（名前に識別子を含め、既存データと区別する）。
- 同じ会員に複数冊貸し出すため、本は所蔵数 4 以上で登録するとよい。
